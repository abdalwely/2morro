# 2Morro Technically Solutions — الموقع الرسمي ولوحة التحكم

موقع مؤسسي عربي (RTL) مع لوحة تحكم إدارية متصلة بقاعدة بيانات.

## التقنيات
- الواجهة: React 19 + Tailwind + React Router + TanStack Query
- الخادم: FastAPI (Python) — جميع المسارات تحت `/api`
- قاعدة البيانات: MongoDB
- المصادقة: JWT (كوكيز httpOnly + Bearer)، كلمات المرور مشفّرة bcrypt
- تخزين الصور: تخزين سحابي (Object Storage) عبر الخادم فقط

## التشغيل محليًا
```bash
# الخادم
cd backend
cp .env.example .env        # ثم عدّل القيم
pip install -r requirements.txt
uvicorn server:app --host 0.0.0.0 --port 8001

# الواجهة
cd frontend
cp .env.example .env        # REACT_APP_BACKEND_URL = عنوان الخادم
yarn install
yarn start                  # للتطوير
yarn build                  # نسخة الإنتاج
```

## إنشاء أول مسؤول
لا توجد كلمة مرور ثابتة في الكود. عند تشغيل الخادم يُنشأ حساب المسؤول تلقائيًا من المتغيرين
`ADMIN_EMAIL` و`ADMIN_PASSWORD` في `backend/.env`. تغيير كلمة المرور في `.env` ثم إعادة التشغيل يحدّث الحساب.

## الصفحات
| المسار | الوصف |
|---|---|
| `/` | الرئيسية |
| `/about` | من نحن |
| `/services`, `/services/:slug` | الخدمات وتفاصيلها |
| `/projects`, `/projects/:slug` | المشاريع وتفاصيلها مع المعرض |
| `/models` | نماذج التنفيذ |
| `/contact` | تواصل معنا (واتساب / بريد / روابط اجتماعية فقط — لا يوجد نموذج داخلي) |
| `/admin` | لوحة التحكم (محمية) |

## دليل إدارة المحتوى
1. ادخل إلى `/admin/login` ببيانات المسؤول.
2. **الإعدادات**: أضف البريد الرسمي ورقم واتساب (بصيغة دولية بدون +) وروابط التواصل والشعار ونصوص الصفحات. أزرار التواصل لا تظهر في الموقع إلا بعد إدخال هذه البيانات.
3. **الخدمات / المشاريع / نماذج التنفيذ**: إضافة، تعديل، حذف (مع تأكيد)، نشر أو مسودة، ترتيب العرض، رفع الصور.
4. خيار **"محتوى تجريبي"**: المحتوى الأولي معلَّم كتجريبي ويظهر عليه وسم «تجريبي» في الموقع. أزل العلامة بعد استبداله ببيانات حقيقية معتمدة.
5. المحتوى غير المنشور (مسودة) لا يظهر للزوار إطلاقًا — يُفلتر على مستوى الخادم.

## الأمان
- كل مسارات `/api/admin/*` تتطلب JWT صالح لدور `admin` (تحقق على الخادم).
- الواجهة العامة تقرأ المحتوى المنشور فقط.
- الصور: يُتحقق من النوع (JPG/PNG/WEBP/GIF) والحجم (حتى 5MB) وتُقدَّم عبر الخادم.
- الأسرار في متغيرات البيئة فقط.

## قاعدة البيانات (Collections)
`users`, `settings`, `services`, `projects`, `delivery_models`, `files`, `activity_log`.
البيانات الأولية تُزرع تلقائيًا عند أول تشغيل (`backend/seed.py`) ولا تُكرر.
